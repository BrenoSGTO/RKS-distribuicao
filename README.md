# Aplicativos RKS

Suíte da RKS Engenharia de Estruturas para Windows 64 bits.

[**Baixar e instalar RKS Launcher**](https://github.com/BrenoSGTO/RKS-distribuicao/releases/latest/download/RKS-Launcher-Instalar.exe)

1. Abra o instalador e clique em **Instalar e abrir**.
2. No launcher, clique em **Instalar tudo** ou escolha um aplicativo.
3. Depois, use **Abrir** e **Atualizar** no próprio launcher.

Para receber o Corte de Telas RKS em uma instalação existente, atualize o próprio launcher para a versão 1.5.0 pelo botão **Atualizar e reiniciar**. Para visualizar os desenhos gerados, use ZWCAD 2020+ ou AutoCAD.

O launcher 1.3.0 traz cores próprias para os aplicativos e modo escuro em **Configurações → Aparência**. Salve a escolha para aplicá-la e mantê-la nas próximas aberturas.

Não é necessário ter conta no GitHub, instalar Python, Node.js ou informar senha de administrador. A instalação ocorre somente para o seu usuário, sujeita às políticas do computador.

Aplicativos: RKS Modelador Plano, RKS Vigas e Lajes, RKS Vigas Metálicas, Gerenciador de Arquivos RKS, RKS | Plotagem de pastas, Calculadora de pilares, RKS Vigas de alvenaria, Corte de Telas RKS. O RKS | Plotagem de pastas depende de AutoCAD ou ZWCAD instalado e licenciado; a referência CAD do modelador depende de ZWCAD. A Calculadora de pilares é independente de Java e do programa original usado como referência; seus limites estão documentados no aplicativo.

O Windows pode exibir avisos de reputação para este instalador ainda sem assinatura digital comercial. Em equipamentos gerenciados, solicite à TI a liberação dos arquivos.

O código dos projetos é mantido em repositórios separados. Os pacotes deste repositório são públicos. Consulte as notas e licenças incluídas nos pacotes.
